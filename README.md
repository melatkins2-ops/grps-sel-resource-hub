Before public launch, test the deployed GitHub Pages URL on desktop and mobile:
- all top navigation
- audience selector
- Find a Resource
- Support a Scholar
- MTSS Center
- modal open/close and Escape
- Home/return behavior
- every external resource link
- district-network access

The visual direction is intentionally frozen unless QA reveals a usability issue.
